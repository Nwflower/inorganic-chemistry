# 紧凑工艺站与原版试剂风格

## 依据

对照本机原版 `PreBuildChemHelper`：酸、碱、还原剂分别使用 `med_bottle_red`、`med_bottle_blue`、`med_bottle_orange` 容器。四种模组化学品现在也用 16×32 图形并实际占 1×2 格，复用细长药瓶轮廓；它们仍是带化学标签的模组物品，不冒充原版液体容器。

盐酸、硝酸、烧碱、氨的原始生图归档在 `originals/`，用于保留各自内容图标与颜色方向。最终运行图改为逐像素复用原版 `med_bottle_red` 的不透明轮廓：椭圆瓶塞顶、收窄瓶颈、圆肩、弧形底托；在瓶身下部画不同颜色的液面带和小型内容符号。16×32 与原版药瓶一致，实际占 1×2 格。每个 `ArtSource/Items/16x/` 文件是对应运行图的 16 倍最近邻放大像素源。

## 占格

`originals/` 还保存本轮开始前的 14 张 48×48 机器贴图和机器框架。游戏通过每个 16×16 单元的中心像素 alpha 确定占格；不是每个旧 48×48 图片都实占 3×3。

- 本工单最初将两张机器贴图改为 32×16、三张改为 16×32、九张改为 32×32。后续开发期整合移除了氯碱槽、压片机、单晶炉和切片机；未删除的图片仅作为工单归档，不再代表这些机器仍会注册。
- 燃料电池的 80×32 图像与动态电池和氢气瓶叠层保持不变。
- 机器框架的中心原本透明，增加中心支架，防止成为零格物品。
- `tools/check_textures.py` 检查中心采样、源图一致性，并与旧图实际占格数量比较；每一张压缩机器图均不增加实占格。
- 旧存档保存了形状，新图的占格不能假设自动迁移到已有机器。未强制修改任何存档。

## 复现与验收

运行 `python Modding/ElementalIndustry/tools/compact_generated_art.py` 从归档输入复现 PNG 和对比图，再运行 `python Modding/ElementalIndustry/tools/check_textures.py`。本次只做开发目录处理与静态检查；未部署、未启动游戏、未验证存档或游戏内视觉。
