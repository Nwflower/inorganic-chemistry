# Silicon inventory icon

The replacement keeps the game's vanilla metal-ingot silhouette and cool silver-blue shading. The generated source is reduced to a hard-edged 16x16 sprite with a limited palette by `tools/generate_silicon_icon.py`.

The source image was generated with the built-in image generation tool from this prompt:

> Redraw the silicon item as a compact, recognizable silicon ingot/crystal, using the exact chunky silhouette and hand-shaded pixel language of the vanilla metal ingot, with cool silver-blue silicon highlights that distinguish it from ordinary iron. One centered 1x1 inventory icon; strict retro pixel art; transparent background; no text or extra objects.

The original generated PNG is retained here as `generated-silicon.png` so the pixel conversion can be reproduced.
