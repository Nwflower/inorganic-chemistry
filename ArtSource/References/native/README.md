# Native Sprite References

- `flux_agent.png` is the 16x16 vanilla flux-agent sprite. The coke icon generator uses this silhouette and recolors its faces to a carbon palette.
- `flux_agent_advanced.png` is the 32x32 advanced flux-agent sprite. It is retained as a scale and material-finish reference alongside the standard item.
- `water_tablet.png` is the exact 16x16 vanilla water-tablet sprite. New chemistry recipes output the vanilla item directly; this copy is only used by the catalog and old-save compatibility entry.

These files are reference material only and are not copied into the runtime mod package.
